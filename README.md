# SFA Live Admin Panel (UAT Environment)

UAT environment for SFA Live Admin Dashboard configured to interface with UAT APIs.

## 🌐 Environment Details
- **API Base URL**: `https://nodeapi.sfalive.shop/api`
- **Game Admin URL**: `https://sfagameadmin.sfalive.shop/login`

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Verify Setup
```bash
node verify-setup.js
```
